# My Qur'an Companion (course index 0)

Status, 15 Nov 2026: **framework playable, Qur'an text and audio pending.**
Scholarly review is required before release.

## What the source contains

One file: `Imaan_Akhlaq_Masnun_Quran_Recitation_Hifz_Developer_Framework.docx`
("Development specification • v1.0"), extracted at
`imaan-email-content-2026-11-14/extracted/01-Quran/…txt` (26,871 characters).

It is a developer specification, not a lesson book. It gives:

* the two experiences: (A) Hifz & Recitation Skills, (B) Masnūn Recitations;
* the M / H / C catalogue labels and their publication rules (§1.2);
* three experiences by proficiency: Picture & Audio, Guided Reciter,
  Independent Explorer (§1.3);
* the screen map (§2), the six-step lesson (§3), seven practice modes (§4.2);
* the revision policy: intervals 0, 1, 3, 7, 14, 30, ~60 days, three review
  outcomes and four mastery states (§4.3);
* the Masnūn catalogue M01–M11 with ayah ranges, Juz, context and Hadith
  references with sunnah.com links (§6, §16);
* the extended pathway with chunk plans for Yā-Sīn, Al-Wāqiʿah, Al-Mulk,
  Al-Kahf 1–10 and 2:285–286 (§7);
* the 30-Juz placement map: start/end ayah, selected ranges with labels and
  a learning focus per Juz (§8);
* all 37 surahs of Juz 30 with ayah counts (§9);
* the suggested learning order in six phases (§10), data contract (§11),
  storyboard for 2:285–286 (§12), progress/privacy and review gates
  (§13–15).

It does **not** contain any Arabic Qur'an text, translations or meanings of
ayat, transliteration or audio. It says so itself: the verse text "must be
imported from a verified Uthmānī Qur'an dataset, not typed or generated by
the developer".

## What was built

All data is in `assets/data/courses/quran-framework.json`, copied verbatim
from the source tables (ranges written with ASCII `-`, shown with `–`).
No Arabic script is stored; a test enforces this. Rebuild it with
`node lib/courses/quran/tool/gen_quran_json.cjs assets/data/courses/quran-framework.json`
(the source tables are in `tool/quran_source_tables.cjs`).

* `quran_data.dart` – loads the JSON; `AyahRef` / `AyahRange` sort and
  compare canonically (surah, then ayah). Juz tags are computed from the
  Juz boundaries, so Yā-Sīn is one lesson tagged Juz 22 & 23.
* `quran_progress.dart` – device-only progress per learner scope
  (`imaan.quran.v1.<scope>`, like `DeviceHadithProgressStore`; no points, no
  Firebase) and `RevisionEngine`, the §4.3 rules:
  * first independent recall → Can Recite Independently, review same day;
  * Confident → next interval; **Retained After Review only after a review
    at least one day after the first recall**;
  * Some prompting → shorter interval (at least next day), Can Recite with Help;
  * Needs re-learning → back to step 1 (listen + echo), schedule and adult
    approval cleared.
* `quran_screens.dart` – home with "one helpful next step" (Today's review /
  Resume / New lesson), placement by proficiency, the two paths, My Learning
  Road (§10), Masnūn Recitations (M01–M11 with citations), Qur'an by Juz
  (30 Juz → selected passages; Juz 30 adds the full 37-surah inventory),
  and a simple grown-up check (multiplication question) for the adult area.
* `quran_lesson.dart` – the six-step lesson for any passage (Hear it, See it,
  Say it with Echo and Loop ×3/5/10 counter and chunk checklist, Understand it
  with the Sunnah context card and label rules, Recall it with an adult
  listening, Keep it with the next review), the Revision Garden, and
  Parents & teachers: listen and record an outcome, approve (only once the
  child recites independently), remove approval, reassign, pause the plan.

Practice works without text, audio or a microphone: the child listens to an
adult and reads from a printed muṣḥaf, and an adult judges the recitation.
The app never scores pronunciation and records no voice.

Choices where the source left gaps (all shown as "pending" in the app):

* "Growing recall" says "other short Juz 30 surahs in an editor-approved
  order". The app lists the remaining Juz 30 surahs from the end backwards
  (the source allows this) and marks the order as pending editor approval.
* "Advanced optional" includes "remaining long surahs", which the source
  does not name; only 32:1–30 and 76:1–31 are listed.
* Reference-only selections (most C entries in §8) have no name in the
  source, so they show as "Qur'an 2:152–153" with the Juz's learning focus.
* The review after "with help" is set to the next day (the source schedule
  starts only at the first independent recall).

## Still needed before release

1. **Uthmānī text — imported 16 Nov 2026** for all 990 ayahs the course
   uses (`assets/data/courses/quran-text.json`, from the Quran.com API by
   `tool/gen_quran_text.cjs`; its SHA-256 checksum is checked by
   `test/courses/quran_text_test.dart`). Hear it and See it show the full
   published verse text, never the per-word list, which can drop small
   tajweed marks (e.g. 2:2). Still to do: an editor spot-checks it against
   a printed Madinah muṣḥaf; decide the Basmala and Sajdah display policy.
2. **Recitation — Mahmoud Khalil Al-Husary (Muallim)**, streamed per ayah
   from mirrors.quranicaudio.com, with word timings that light up the word
   being recited, and each ayah repeatable ×1/×3/×5. Still to do: confirm
   commercial-use permission with the Quran Foundation / QuranicAudio, and
   an offline cache.
3. **Approved phrase chunks** for long ayahs (2:255, 2:285, 2:286).
4. **Child-friendly meanings** in English/Urdu from a Tafsir editor (only the
   2:285–286 storyboard theme exists in the source).
5. **Hadith review** of every M context wording and grading (M01–M11),
   especially the ḥasan ones (M06, M08).
6. Editor-approved order for "Growing recall" and the "remaining long
   surahs".
7. Not built in this version: private voice recording / Listen & compare
   (needs consent flow), daily minute cap and reminder settings, offline
   audio cache, other qirāʾāt.

Tests: `test/courses/quran_test.dart` (source data rules, acceptance checks
from §15, revision engine, store, and widget flows at 375 px with text ×1,
×1.5 and ×2).
