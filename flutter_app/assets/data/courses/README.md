# Course data

One folder-free set of JSON files per course, named `<course>-*.json`
(for example `duas-volume-01.json`). pubspec bundles this whole directory,
so a course adds its files here without editing pubspec.yaml.

Flutter bundles only the files directly in this directory, not subfolders.
